# Frontend deployment — 10 November 2026

Target: https://gateshield.pro. Reviewed upstream commits `55f124b` and
`b030c31`. Deployed source including regression tests: `c2e1927`.

The release updates operator dashboard SVG icons/theme, employee header/layout,
operator/admin account management, camera presentation/capture behavior, and
delivery-document visibility. Incoming and outgoing delivery documents are now
optional; a provided image must still be valid. A new visit must not display
an earlier visit's delivery document. QR lookup uses visit-specific image flags.
